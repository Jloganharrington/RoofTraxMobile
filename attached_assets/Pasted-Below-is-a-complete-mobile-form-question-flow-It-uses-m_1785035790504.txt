Below is a complete mobile-form question flow. It uses mostly radio selectors, yes/no/unknown choices, and conditional evidence requirements. It is designed so the app can produce a defensible repairability record without letting users jump straight from “damage exists” to “full replacement required.”

Use the same validation rules as roofing:

“Does not support reliable spot repair” requires at least two basis factors, including one direct-test or product-evidence factor.

Universal Evidence Rules
Apply these to both sections:

Any answer that supports a conclusion must require a linked photo, video, measurement, sample, manufacturer document, laboratory report, supplier search, or test record.
A user cannot select “discontinued” as confirmed without a linked manufacturer or distributor source.
A user cannot select “not sourceable” without a documented supplier/manufacturer search.
A user cannot select “adjacent material fractured” unless a controlled test was performed.
A user cannot select “could not reset” without a linked test record or manufacturer instruction.
The app must never output “full replacement required.”
The app may output only:
Spot repair supported
Spot repair conditionally supported
Documented evidence does not support reliable spot repair
Repairability cannot yet be determined
Temporary weather protection is recorded only as a consequence of a controlled test or emergency condition—not as evidence that repair is impossible.
