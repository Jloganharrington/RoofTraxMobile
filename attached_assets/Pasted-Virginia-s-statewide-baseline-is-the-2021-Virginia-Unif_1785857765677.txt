Virginia’s statewide baseline is the 2021 Virginia Uniform Statewide Building Code (USBC) for permits issued on or after January 18, 2025. For roof work, the code path depends first on building type:

Detached one- and two-family homes and qualifying townhouses → 2021 Virginia Residential Code (VRC)
Commercial buildings, multifamily outside VRC scope, mixed use, and other non-VRC buildings → 2021 Virginia Construction Code (VCC), using the IBC framework as amended
Repair, reroofing, recover, or alteration of existing structures → 2021 Virginia Existing Building Code (VEBC), plus the applicable VRC/VCC new-work requirements
This is the comprehensive statewide map for asphalt shingles, cedar shingles/shakes, and standing-seam metal. Local building departments enforce the USBC, so permit scope, inspection sequence, wind design inputs, and any locally authorized overlay still need AHJ confirmation.

Cedar is not code-compliant simply because it is cedar. The actual shake/shingle product, listing, treatment, assembly, fire rating, fasteners, deck, and installation method matter.
