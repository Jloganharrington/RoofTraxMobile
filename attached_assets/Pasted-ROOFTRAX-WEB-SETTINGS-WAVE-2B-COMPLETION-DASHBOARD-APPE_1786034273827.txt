TASK D1 [LOCKED] — Dashboard tab: widget visibility + order
════════════════════════════════════════════════════════════
Layout shape stored in user_profiles.dashboard_layout:
    { hidden: string[], order: string[] }
Widget KEYS only, never titles.

SERVER RULE — this is the security-relevant part, get it exact.
GET /dashboard/manifest applies the stored layout AFTER selectWidgetsFor().
The capability-resolved set is the universe; layout is only a view on it.
  - hidden: subtracts keys from the resolved set. Keys not in the resolved
    set are ignored — they subtract nothing and add nothing.
  - order: sorts the remaining resolved keys. Keys not in the resolved set
    are dropped. Resolved widgets NOT listed in order append AFTER the
    ordered ones, in catalog order. This is required so a newly shipped
    widget appears for users with saved layouts instead of vanishing.
  - Stale/unknown keys anywhere in the layout are ignored silently. A
    catalog change must never 500 a manifest request.
  - A layout can NEVER add a widget. There must be no code path where a key
    in the stored layout reaches the response unless the resolver granted it.

API (openapi-first, then regenerate):
  - PATCH /dashboard/layout — body { hidden: string[], order: string[] },
    self-only (operates on req.user.id, no target-user param). Validate:
    arrays of strings, length cap 50 each, no other fields accepted.
  - DELETE /dashboard/layout — nulls the column (restore defaults).

UI — Dashboard tab, replacing the ComingSoonStub:
  - List the user's GRANTED widgets. Source that list from the MANIFEST
    response, never from WIDGET_CATALOG directly — the manifest IS their
    universe and reading the catalog would show widgets they can't have.
  - Per row: a visibility toggle and up/down reorder buttons. No
    drag-and-drop unless something already installed makes it trivial.
  - "Restore defaults" button calls the DELETE.
  - On save, invalidate the manifest query so the dashboard reflects changes
    without a full page reload.
