# WORK ORDER — Rename RoofTrax → AxiomRestore

**Mode:** Build. **Baseline:** workspace suite plus the 130-test negative suite.
**Canonical form:** `AxiomRestore` — one word, capital A, capital R, everywhere. Never `Axiom Restore`, never `axiomRestore`, never `Axiomrestore`.
**One step per commit.** Steps run in order; the sequence is what keeps the build alive.

**Scale:** 183 occurrences across 104 source files, plus docs and memory. Concentrated in `artifacts/rooftrax-web` (30), `artifacts/api-server` (19), `artifacts/mobile` (15), `lib/db` (4).

**Do not do a global find-and-replace.** The string `rooftrax-web` appears in import paths, workspace config, and launch config. A blind replace breaks the build in a way that's tedious to unpick.

---

## STEP 0 — Inventory (report only)

Produce the complete list before changing anything:

```bash
grep -rn "RoofTrax\|rooftrax\|ROOFTRAX" . \
  --include="*.ts" --include="*.tsx" --include="*.json" --include="*.html" \
  --include="*.md" --include="*.yaml" --include="*.yml" --include="*.sql" \
  --include="*.toml" --include="*.sh" --include="*.mjs" \
  | grep -v node_modules
```

Also check the files that extension filter misses: `.replit`, `.gitignore`, `.env.example`, any dotfile, and `pnpm-lock.yaml`.

Classify every hit into one of five buckets:

| Bucket | Treatment |
|---|---|
| **Identity** | Bundle ID, app name, slug, scheme — Step 1 |
| **Customer-facing** | Templates, emails, documents, marketing copy — Step 2 |
| **Path** | Directory names, imports, workspace config — Step 3 |
| **Source** | Variable names, comments, test descriptions — Step 4 |
| **Historical** | Docs, memory, `attached_assets/`, audit findings — Step 5 or leave |

▶ **CHECKPOINT 0** — Paste the classified inventory with a count per bucket. **Stop.**

## STEP 1 — Mobile identity and strings

**The only irreversible change in this order.** A published app's bundle identifier cannot be changed; doing so later means a new listing, a lost URL, lost reviews, and a forced reinstall for every user.

`artifacts/mobile/app.json`:

```
"name":             "RoofTrax"          → "AxiomRestore"
"slug":             "mobile"            → leave, or "axiomrestore-mobile"
"scheme":           "mobile"            → leave, or "axiomrestore"
"ios.bundleIdentifier":  "com.rooftrax.mobile" → "com.axiomrestore.mobile"
"android.package":       "com.rooftrax.mobile" → "com.axiomrestore.mobile"
```

Leave `extra.eas.projectId` as the placeholder — that's a separate outstanding item.

Then the 15 other files in `artifacts/mobile` carrying the string.

**Report before changing:** whether `slug` or `scheme` are referenced anywhere — deep links, OAuth redirect URIs, `expo-router` config, the OIDC callback. If either is wired into an auth redirect, changing it breaks login and it stays as-is.

`artifacts/mobile` has already diverged from the build Logan tested, so this pass ends with a **full manual regression on the app**: login, inspection creation, field capture, photo upload, FIPSA generation, submission.

▶ **CHECKPOINT 1** — Diff, the slug/scheme finding, and the regression result.

## STEP 3 — Directory rename, isolated

`artifacts/rooftrax-web` → `artifacts/axiomrestore-web`

Use `git mv` so history follows. Then update every reference:

- `pnpm-workspace.yaml`
- root and per-package `package.json`
- `.claude/launch.json`
- `.replit`
- any import, alias, or `tsconfig` path mapping
- CI or deploy config referencing the path

**This is the step that can break the build.** It gets its own commit, and it ends with `pnpm -w tsc --build --force` from the repo root — per-artifact checks pass against stale `dist` and will not catch a broken path.

▶ **CHECKPOINT 3** — Diff, root typecheck output, and a successful dev-server start.
